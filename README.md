# Snake Game 🐍

A simple terminal-based Snake game written in Python using the built-in `curses` library.

## Requirements

- Python 3.x (no external packages needed)

## How to Run

```bash
python3 snake.py
```

## Controls

| Key | Action |
|-----|--------|
| ↑ ↓ ← → | Move the snake |
| `q` | Quit the game |

## Rules

- Eat the red food (`●`) to grow and earn **10 points**
- Avoid hitting the walls or your own body
- The game ends on collision — try to beat your high score!
